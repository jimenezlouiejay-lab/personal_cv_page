# Louie Jay Y. Jimenez — Personal CV Portfolio

A responsive personal Curriculum Vitae and portfolio website created for **Louie Jay Y. Jimenez**, a 4th Year BS Information Technology student at Davao del Norte State College.

The website presents my professional profile, education, technical and professional skills, selected projects, academic experience, technical highlights, GitHub profile, and contact information in a modern black, gold, and blue visual style.
